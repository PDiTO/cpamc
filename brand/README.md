# Prox brand

The Prox mark: a Codex-blue line and a Claude-orange line that blend where they meet and fade
into one white line. Used by the Prox dashboard and the T3 Code fork.

| File | Use |
| --- | --- |
| `prox-icon.svg` | App icon and favicon: the mark on a dark rounded tile. The dashboard imports this file. |
| `prox-icon-{16,32,64,180,256,512,1024}.png` | The app icon at fixed sizes (180 is the Apple touch icon size). |
| `prox-mark-on-dark.svg` | The mark alone, fading to white, for dark backgrounds. |
| `prox-mark-on-light.svg` | The mark alone, fading to ink (#141821), for light backgrounds. |
| `prox-lockup-on-dark.png`, `prox-lockup-on-light.png` | Mark with the Prox wordmark, 1200 × 400. |

Colors: Codex blue `#4D8DFF`, Claude orange `#F2783A`, tile `#0F1219`, ink `#141821`.
Wordmark: Sora SemiBold, letter-spacing −0.03em.

The SVGs are the source. PNGs were rendered from them with headless Chrome; re-export them after
editing an SVG.
